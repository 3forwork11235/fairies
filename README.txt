==========================================
     🧚 ФЕИ — волшебный сад — инструкция
==========================================

Феи летают над садом и тянут за собой дорожку из лепестков.
Вылетела из своего сада, обвела кусочек земли, вернулась домой —
всё обведённое расцветает твоими цветами. Коснись чужой дорожки —
та фея заснёт и проснётся у себя дома. Когда время выйдет,
побеждает фея с самым большим садом (больше половины — победа сразу).

  Сайт игры: https://3forwork11235.github.io/fairies/

ФАЙЛЫ
-----
  index.html        — страница игры: меню, бутик, экраны, оформление
  game.js            — рисование фей и сада, звук и музыка, бутик,
                       задания дня, достижения, открытка, управление
  net.js             — связь: P2P, запасной канал, server.py, переподключение
  room.js            — комната: сад по клеткам, дорожки, чары, бонусы,
                       боты, раунды (работает в браузере создательницы игры)
  sw.js, manifest.webmanifest, icons\ — чтобы игру можно было «установить»
                       на телефон как приложение (PWA)
  server.py          — запасной сервер для игры по Wi-Fi без интернета
  start_server.bat   — запуск сервера (игра по Wi-Fi)
  start_online.bat   — игра через интернет с сервером на ноутбуке (Tuna)
  open_firewall.bat  — один раз открыть порт 8767, если телефоны не подключаются
  requirements.txt   — зависимость Python (websockets)


ПРАВИЛА
-------
  🧚 Фея летит сама — выбираешь только направление.
     Телефон: веди пальцем, джойстик появится под пальцем.
     Компьютер: мышь (фея летит к курсору) или WASD / стрелки.
  ✨ Вспышка — короткий рывок: кнопка-звёздочка, пробел или клик.
     Второй палец на экране — тоже вспышка.
  🌸 Вне своего сада за тобой тянется дорожка. Вернись — и обведённое твоё,
     даже если там был чужой сад.
  🪄 Голова феи на чужой дорожке — хозяйка дорожки засыпает (2,6 с)
     и просыпается дома. Если сад отняли целиком — в новом садике.
  Бонусы: 🦋 скорость, 🫧 пузырь (дорожку нельзя порвать), 🌈 радуга
     (цветёт круг вокруг), ❄️ иней (замедляет соседок), 💎 кристаллы.
  🌹 В середине раунда — волшебная роза: большой круг сада и пузырь.
  🌠 Потом — звездопад: по саду рассыпаются кристаллы.
  1–9 на клавиатуре — быстрые фразы, Esc — пауза (в игре с ботами).


ЧТО ЕЩЁ ЕСТЬ
------------
  ✨ Волшебный бутик — крылья (6 видов), украшения (8), дорожки (6),
     питомцы (5), которые летают за феей. Покупаются за 💎 кристаллы.
     Самые красивые вещи открываются только достижениями.
  💎 Кристаллы дают за каждый раунд: за размер сада, место, чары,
     собранные кристаллы. На старте — подарок 50 💎.
  📅 Задания дня — три новых задания каждый день, за все три — бонус.
  🏆 Достижения — 13 штук, со статистикой.
  📸 Открытка — после раунда можно сохранить картинку с садом и тройкой лучших.
  🎵 Своя музыка (вальс), звуки-колокольчики, вибрация на телефоне.
  Всё сохраняется в браузере на этом устройстве.


1. ПРОТИВ БОТОВ (одно устройство, без сети)
-------------------------------------------
Открой игру → «Против ботов». Настройки сада (сколько фей, какие боты,
длина раунда, матч до N побед, бонусы, пруды) — в меню «Настройки сада».


2. ОНЛАЙН НАПРЯМУЮ (P2P) — без сервера и без компьютера
-------------------------------------------------------
Сервером становится браузер той, кто создаёт игру. Остальные
подключаются к ней напрямую (WebRTC).
1. «Играть с подругами» → «Полетели!» (в «Связь» выбрано «Напрямую (P2P)»).
2. Отправь подругам ссылку (вида …/#p2p=ABC123), кнопку «Поделиться»
   или 6-значный код. Играть могут от 2 до 16 человек.
3. «Начать!» — свободные места займут феи-боты (если включены).
   Если все места заняли люди, игра начнётся сама.
4. Если прямой канал не открывается (мобильный интернет, VPN), через 6 секунд
   гость сам переходит на запасной канал — публичный сервер сообщений (MQTT).
5. Создательнице игры лучше не сворачивать браузер: на телефоне в фоне
   игра у всех замирает. Если вкладку перезагрузили — игра поднимется,
   гости переподключатся сами.


3. ИГРА ПО WI-FI ЧЕРЕЗ СЕРВЕР НА НОУТБУКЕ (работает без интернета)
------------------------------------------------------------------
1. На ноутбуке запусти start_server.bat. В окне появятся адреса,
   например:  http://192.168.1.5:8767
2. Все устройства — в той же Wi-Fi сети, что и ноутбук.
3. Открой этот адрес на телефонах — связь через сервер выберется сама.
4. Не открывается — один раз запусти open_firewall.bat.
